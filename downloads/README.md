# Downloads

Baixe a versão identificada por BUILD na página de [Releases do Screwvivors](https://github.com/vbg16/robots-zombies/releases).

- **Pacote do jogo:** asset `Screwvivors-BUILD…-jogo.zip` da release. Extraia tudo e abra `index.html`.
- **Código completo:** **Code → Download ZIP** na `main`, incluindo testes, documentação e evidências.
- **ZIP antigo:** a pasta [historico](historico/README.md) preserva um protótipo antigo; não contém as atualizações atuais.

As versões de desenvolvimento são pré-lançamentos. O arquivo `.sha256` da release permite conferir a integridade do pacote baixado.
