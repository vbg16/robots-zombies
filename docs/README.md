# Screwvivors — direção do projeto

## Base técnica aprovada — 27/10/2026

O criador aprovou continuar o desenvolvimento do protótipo no navegador com HTML, CSS e JavaScript, aproveitando o código existente, sem migrar para Godot agora. O assistente ficará responsável pela maior parte da programação; o criador orientará as decisões e testará as versões. A prioridade é validar movimento, disparo manual e sinergias. Empacotamento para Windows/Linux e integração Steam serão avaliados posteriormente; nenhuma ferramenta de empacotamento ou biblioteca adicional foi escolhida. Esta decisão não altera as regras de design nem significa que as funcionalidades planejadas estejam implementadas.


Este diretório é a fonte de referência para as decisões de produto e design do jogo. Consolida a conversa de definição do projeto até 27/10/2026.

## Como interpretar

- **Confirmado:** definido ou esclarecido pelo criador na conversa.
- **Proposto:** recomendação de trabalho; não constitui decisão aprovada.
- **Pendente:** ainda exige definição ou teste. Não preencher silenciosamente com uma suposição.

Os documentos descrevem o jogo pretendido. Não significam que todas as funcionalidades já estejam implementadas. O protótipo HTML atual é experimental e diverge de regras aprovadas; consulte o plano de desenvolvimento.

Não há data de lançamento, preço, orçamento aprovados; a base atual é HTML/CSS/JavaScript no navegador. O nome Screwvivors é de trabalho e ainda requer verificação de disponibilidade.
